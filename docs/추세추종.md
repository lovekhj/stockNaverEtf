# ETF 주도주 기반 주체추종 & 피라미드 매수 전략 가이드

## 1. 개요 및 핵심 원칙
- **목적**: 초보 투자자도 **원금 손실 위험을 극소화**하면서, 외국인·기관이 사 모으는 ETF 상위 주도주(`etf_top_stocks.csv`)를 중심으로 **안전하게 수익을 극대화**하는 투자 전략입니다.
- **핵심 조합**: **주체추종(외국인/기관 쌍끌이 수급)** + **원금보전형 피라미드 분할매수(Pyramid Buying)**

---

## 🛡️ 피라미드 매수 2대 철칙

### 1) 절대 '물타기(주가가 떨어질 때 추가 매수)' 금지
- 주가가 내려갈 때 사는 '물타기'는 손실을 더 크게 만듭니다.
- 피라미드 매수는 오직 **"내가 산 주식이 올라서 수익이 날 때만(외인/기관 수급 지속 시)"** 추가 매수(불타기)를 진행합니다.

### 2) 아래는 넓게, 위로는 좁게 피라미드 탑 쌓기
- 1차 매수 시 가장 비중을 크게 실어 기초를 다지고, 올라갈수록 매수 수량을 줄여 평균 매수가가 너무 급하게 올라가는 것을 방지합니다.

```text
       ▲
      / 4차: 10% (마지막 확인 매수)
     /--- \
    / 3차: 20% (추가 시세 솟구칠 때)
   /----- \
  / 2차: 30% (주가 +3%~5% 상승 시)
 /------- \
/ 1차: 40% (외인/기관 쌍끌이 시작 시)
```

---

## 📐 실전 4단계 피라미드 매수 매뉴얼

> **예시**: 총 투자금 1,000만 원 기준

### 1단계: 종목 고르기 (안전한 주도주 선정)
- `etf_top_stocks.csv` 상위 20위 이내의 **대한민국 대표 우량 주도주**(삼성전자, SK하이닉스, KB금융, 현대차, 알테오젠 등) 중에서만 선택합니다.
- 잡주나 부실주는 절대 매수 대상에서 제외합니다.

### 2단계: 1차 씨앗 매수 (전체 자금의 40% = 400만 원)
- **매수 타이밍**: 외국인과 기관(연기금)이 3일 이상 연속으로 동시에 사 모으는(쌍끌이) 신호 확인 시 1차 진입.
- **🛡️ 1차 안전장치 (손절선 -3%)**:
  - 매수 후 주가가 **-3%** 떨어지면 미련 없이 즉시 손절합니다.
  - 이 경우 전체 원금(1,000만 원) 대비 손실은 **겨우 12만 원(-1.2%)**에 불과하여 원금 98.8%가 안전하게 보호됩니다.

### 3단계: 피라미드 불타기 추가 매수 (수익 발생 시에만 진행)

#### ① 2차 매수 (전체 자금의 30% = 300만 원)
- **조건**: 1차 매수 후 주가가 **+3% ~ +5% 상승**하고, 외인/기관 수급이 계속 유지될 때.
- **🛡️ 2차 안전장치 (본전 방어 스탑로스)**:
  - 2차 매수 완료 즉시 **자동 매도(스탑로스) 가격을 1차 매수가(본전)로 상향** 설정.
  - 이후 주가가 꺾여 내려오더라도 본전에서 자동 전량 매도되므로 **손실금액은 0원 (원금 100% 보존)**이 됩니다.

#### ② 3차 매수 (전체 자금의 20% = 200만 원)
- **조건**: 주가가 2차 매수 후 추가로 **+5% 이상 더 솟구칠 때**.
- 평균 매수가가 주가보다 한참 아래에 형성되어 **원금 손실이 불가능한 무적의 상태**에 진입합니다.

#### ③ 4차 매수 (전체 자금의 10% = 100만 원)
- **조건**: 시세 분출이 계속 이어질 때 마지막 100만 원을 올려 피라미드를 완정합니다.

### 4단계: 수익 실현 (트레일링 스탑 익절)
- 주가가 지속 상승하다가 **최고점 대비 -5% ~ -7% 정도 밀려 내려오면 전량 매도**하여 수익을 확실하게 챙깁니다.

## 6. 외국인/기관 수급 & 이동평균선 자동 포착 스크립트 (`getEtfInvestorFlow.py`)

### 1) 기능 및 목적
- `etf_top_stocks.csv` (320개 주도주) 목록을 기반으로 네이버 증권의 수급 API 및 일별 가격 API를 연동하여 **외국인/기관의 연속 순매수(쌍끌이)** 뿐만 아니라 **5일, 20일, 60일, 120일 이동평균선**, **20일선위 여부(O/X)**, **정배열 여부(O/X)**를 자동 계산합니다.

### 2) 실행 방법
```bash
# 320개 ETF 주도주 수급 및 5/20/60/120일 이동평균선 분석 (etf_investor_flow.csv 저장)
python3 getEtfInvestorFlow.py
```

### 3) 이동평균선 산출 알고리즘 및 코드 로직 (`fetch_moving_averages`)
- **수집 데이터**: 네이버 증권 일별 가격 API(`https://m.stock.naver.com/api/stock/{code}/price?page=1~2&pageSize=60`)를 통해 종목별 **최근 120 영업일간의 종가(Close Price)** 배열을 수집합니다.
- **이동평균선 계산 공식**:
  - `MA5` = 최근 5일 종가 단순 평균 (`sum(close_prices[:5]) / 5`)
  - `MA20` = 최근 20일 종가 단순 평균 (`sum(close_prices[:20]) / 20`)
  - `MA60` = 최근 60일 종가 단순 평균 (`sum(close_prices[:60]) / 60`)
  - `MA120` = 최근 120일 종가 단순 평균 (`sum(close_prices[:120]) / 120`)
- **판정 및 안전 지표 연산**:
  - **`20일선위` (`O`/`X`)**: `현재가 >= MA20` 일 때 **`O`**
  - **`정배열여부` (`O`/`X`)**: `MA5 >= MA20 >= MA60 >= MA120` 순서로 정렬될 때 **`O`** (대세 상승장 판별)
  - **`20일이격도(%)`**: `(현재가 / MA20) * 100` (20일선 대비 주가 이격 정도)
  - **`과열여부`**: 이격도 115% 이상 시 **`단기과열(경계)`** (추격매수 금지), 97~108% 시 **`적정(안전)`**
  - **`추세단계`**: `정배열가속(A+)`, `수급우량(A)`, `추세초입(B)`, `단기과열(경계)`, `관망(C)`
  - **`추천매수가`**: `MA20 지지가` ~ `MA5 지지가` (눌림목 안심 진입 구간)

## 7. `etf_investor_flow.csv` 데이터 활용 수급 & 이동평균선 통합 분석법

### 1) 핵심 분석 지표 및 판단 기준

| 분석 항목 | 의미 및 판단 기준 | 매집 판단 조건 |
| :--- | :--- | :--- |
| **쌍끌이여부 (`O`)** | 외국인과 기관이 동시에 순매수 중인 종목 | **최우선 관심 종목 (수급 주도주 1순위)** |

### 3) 실전 3단계 수급 + 이동평균선 필터링 매뉴얼

#### 1단계: 1차 등급 필터링 (A+ / A 등급 선택)
- `etf_investor_flow.csv`에서 **`투자등급`이 `A+` 또는 `A`인 종목**을 먼저 선택합니다.
- 등급 순서(`A+` → `A`)로 정리되어 있으므로 상위 종목부터 쉽게 정렬하여 보실 수 있습니다.

#### 2단계: 2차 수급 및 이평선 교차 검증
- **`A+` 등급 종목**: 수급과 이평선 정배열이 완벽하게 맞물린 주도주이므로 최우선 타겟으로 지정합니다.
- **`A` 등급 종목**: 외국인/기관 수급과 20일선 위 위치가 확인된 우량주이므로 눌림목 형성 여부를 체크합니다.

#### 3단계: 피라미드 진입 전략 (40% → 30% → 20% → 10%)
- **20일선 부근 눌림목 반등** 시 1차 씨앗 매수(40%)로 안전하게 진입합니다.
- 주가가 상승하여 수익이 날 때만 불타기 매수(30% -> 20% -> 10%)를 진행하며, -3% 손절선을 엄격히 준수합니다.

- 기관 수급 전체 중 **'연기금'**의 매집 데이터만 별도로 추적·분석하고자 할 경우, 개별 종목 매매동향 API를 연동하여 `etf_investor_flow.csv`에 `연기금연속매수(일)` 및 `최근3일연기금순매수` 컬럼을 확장 수집할 수 있습니다.
