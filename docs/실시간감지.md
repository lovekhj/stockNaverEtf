# 내 포트폴리오 실시간 시세 감시 및 -3% 손절 알림 시스템 설계 명세서

## 1. 개요 및 목적
본 시스템은 투자자가 매수한 ETF 상위 주도주 목록과 실제 매수가격을 관리하고, 파이썬 스크립트 및 웹 대시보드를 통해 **장중 실시간 시세를 자동 추적 감시**하는 모듈입니다.

주가가 **1차 매수가격 대비 -3% 손절선**을 터치하거나 **전일 종가 대비 -3% 이상 기습 하락**하는 경우, 브라우저 팝업 알림, 경고음, 텔레그램(Telegram) 메시지 등을 통해 즉시 **매도 경고(Stop-Loss Alert)**를 전달하여 원금을 안전하게 보호합니다.

---

## 🛡️ 2. 손절 감지 3대 핵심 알고리즘

### 1) 매수가 대비 -3% 절대 손절선 (원금 보전 철칙)
* **공식**: `((실시간 현재가 - 1차 매수가) / 1차 매수가) * 100 <= -3.0%`
* **작동**: 매수 진입 후 주가가 -3% 떨어지면 즉시 손절 경고 발송. 
* **효과**: 판단 오류 시에도 전체 원금 대비 손실을 **-1.2% 이내로 엄격히 통제**.

### 2) 전일 종가 대비 -3% 갭하락 손절선 (장중 변동성 방어)
* **공식**: `((실시간 현재가 - 어제 종가) / 어제 종가) * 100 <= -3.0%`
* **작동**: 장 시작 후 기습적인 음봉 급락이나 악재로 전일 종가 대비 -3% 이상 밀릴 때 매도 경고.

### 3) 2차 매수(불타기) 후 본전 방어 스탑로스
* **공식**: `2차 매수 완료 후 실시간 현재가 <= 1차 매수가 (본전)`
* **작동**: 주가가 +3%~+5% 상승하여 2차 매수(30%)를 마친 후, 주가가 다시 꺾여 1차 매수가로 복귀하면 **손실금액 0원(본전)에서 즉시 전량 매도**.

## 🛠️ 4. 시스템 아키텍처 및 구현 방안

본 시스템은 **웹 대시보드(Front-end)** 및 **파이썬 백그라운드 감시기(Back-end)** 2가지 모듈로 구성됩니다.

```text
┌─────────────────────────────────────────────────────────────┐
│ 1. 포트폴리오 데이터 입력 (웹 UI / data/my_portfolio.json)    │
└──────────────────────────────┬──────────────────────────────┘
                               │
               ┌───────────────┴───────────────┐
               ▼                               ▼
┌──────────────────────────────┐ ┌──────────────────────────────┐
│ [모듈 A] 웹 대시보드 감시 모듈 │ │ [모듈 B] 파이썬 실시간 스크립트│
│ - 1~3분 주기 Polling         │ │ - monitorPortfolio.py (1분)  │
│ - 웹 브라우저 경고음 & 팝업   │ │ - 텔레그램 BOT 푸시 알림     │
└──────────────────────────────┘ └──────────────────────────────┘
```

---

### [모듈 A] 웹 대시보드 [💼 내 포트폴리오 감시] UI 탭
1. **대시보드 UI 연동**: `index.html` 좌측 메뉴에 `💼 내 포트폴리오` 탭 추가.
2. **매수 종목 등록/수정 폼**: 종목 선택, 매수가격, 수량, 1차/2차 피라미드 단계 입력.
3. **실시간 시세 파싱**: `fetch` API를 통해 네이버 증권 시세 API(`https://m.stock.naver.com/api/stock/{code}/price`)를 1~3분 주기로 자동 조회.
4. **시각적 알림 메시지**:
   - 손절선(-3%) 터치 시 해당 종목 카드가 **빨간색 점멸 경고(Blink Alert)**로 변경.
   - 브라우저 알림음(`Audio API`) 재생 및 **"🚨 [손절 경고] 한미사이언스 -3.1% 터치! 매도 권장"** 모달 팝업 출동.

---

### [모듈 B] 파이썬 백그라운드 감시 스크립트 (`monitorPortfolio.py`)
1. **장중 스케줄러**: 장 개장 시간(09:00 ~ 15:30) 동안 1분 단위로 `my_portfolio.json` 종목들의 시세를 순회 조회.
2. **텔레그램 알림봇 연동**:
   - 손절 조건 충족 시 투자자의 스마트폰 텔레그램 앱으로 즉시 알림 메시지 전송:
   ```text
   🚨 [긴급 매도 손절 알림]
   ---------------------------------
   - 종목명: 한미사이언스 (008930)
   - 매수가격: 53,000원
   - 현재가격: 51,400원 (수익률: -3.02%)
   - 판단결과: 1차 손절선(-3%) 하향 이탈
   ---------------------------------
   👉 즉시 전량 매도를 권장합니다!
   ```

## 🚀 5. 구체적인 개발 단계 (Roadmap)

1. **1단계 [데이터 포맷 정의]**: `data/my_portfolio.json` 저장 구조 생성 및 관리 스크립트 준비.
2. **2단계 [웹 대시보드 탭 구축]**: `index.html` 및 `app.js`에 [내 포트폴리오] 관리 탭 및 실시간 시세 연동 연산 구현.
3. **3단계 [알림 팝업 및 경고음 탑재]**: -3% 손절 진입 시 웹 브라우저 Sound & Modal 경고 시스템 연결.
4. **4단계 [파이썬 텔레그램 알림봇 개발 (선택)]**: `monitorPortfolio.py` 파이썬 스크립트 작성 및 텔레그램 API 연동.
