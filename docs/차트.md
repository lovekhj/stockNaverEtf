# 📊 주식 차트 분석 기초: 캔들과 꼬리(Shadow / Wick) 완벽 가이드

## 1. 캔들과 꼬리(Shadow)란?

주식 차트(캔들차트)에서 **꼬리(Shadow / Wick)**는 특정 시간(일봉, 주봉 등) 동안 주가가 움직인 **최고가와 최저가의 극단적 변동 흔적(발자국)**을 나타냅니다.

* **몸통 (Body)**: 시가(시작 가격)와 종가(마감 가격) 사이의 실질적 거래 형성 구간
* **윗꼬리 (Upper Shadow)**: 장중 최고가와 몸통 상단 사이의 영역 (매도 압력의 흔적)
* **아래꼬리 (Lower Shadow)**: 장중 최저가와 몸통 하단 사이의 영역 (매수 방어의 흔적)

```text
       │     <-- [ 윗꼬리 ] : 당일 최고가 (장중 최고점 형성 후 밀려난 자국)
    ┌──┴──┐
    │     │
    │ 몸통 │ <-- [ 몸통 ]   : 시가와 종가 (최종 매수/매도 승부 결과)
    │     │
    └──┬──┘
       │     <-- [ 아래꼬리 ] : 당일 최저가 (장중 최저점 형성 후 튕겨 오른 자국)
```

## 2. 꼬리의 종류와 핵심 해석

### ① 긴 윗꼬리: "위에서 세게 짓눌렀다!" (위험 ⚠️)
* **상황**: 장중에 주가가 크게 올랐으나, 상단에서 강력한 매도세(차익 실현 및 매물대 저항)가 쏟아져 가격이 다시 밀려 내려온 형태입니다.
* **비유**: 공을 위로 던졌지만 천장에 **쾅!** 맞고 떨어진 모습
* **주가 신호**: **하락 / 조정 가능성 증대** (고점권 출현 시 매도 전환 시그널)

```text
       │
       │    <-- 긴 윗꼬리 (매도세가 강하게 짓누름)
       │
    ┌──┴──┐
    └──┬──┘ <-- 작은 몸통
```

### ② 긴 아래꼬리: "밑에서 든든하게 받쳤다!" (기회 🟢)
* **상황**: 장중에 주가가 크게 밀렸으나, 하단에서 강력한 저가 매수세가 유입되어 주가를 올려 세운 형태입니다.
* **비유**: 고무공을 바닥에 쳤더니 바닥을 튕기고 **뿅!** 하고 올라온 모습
* **주가 신호**: **상승 / 반등 가능성 증대** (바닥권 출현 시 저점 확인 시그널)

```text
    ┌──┴──┐ <-- 작은 몸통
    └──┬──┘
       │
       │    <-- 긴 아래꼬리 (매수세가 밑에서 강력하게 받쳐 올림)
       │
```

## 3. 대표적인 꼬리 캔들 패턴

| 패턴명 | 캔들 형태 | 발생 위치 | 시장 의미 및 해석 |
| :--- | :--- | :--- | :--- |
| **망치형 (Hammer)** | 긴 아래꼬리 + 상단 작은 몸통 | 바닥권 (하락 추세 말기) | 강력한 저가 매수세 유입 → **상승 반전 시그널** |
| **유성형 (Shooting Star)** | 긴 윗꼬리 + 하단 작은 몸통 | 고점권 (상승 추세 말기) | 상단 매물 대량 출회 → **하락 반전 시그널** |
| **십자형 (Doji)** | 위아래 꼬리 + 매우 얇은 몸통 | 추세 진행 중 | 매수/매도 힘겨루기 팽팽 → **추세 전환 경계 시그널** |

---

## 4. 실전 매매 활용 팁

1. **꼬리 길이의 중요성**: 꼬리가 몸통 대비 2~3배 이상 길수록 지지나 저항의 강도가 매우 큽니다.
2. **거래량과의 결합**: 대량 거래가 동반된 아래꼬리는 세력 및 기관/외인 수급 유입의 강력한 증거가 됩니다.
3. **이동평균선 지지 여부**: 20일선 등 핵심 이평선 부근에서 긴 아래꼬리가 발생할 경우 정배열 추세 지속 가능성이 높습니다.

## 5. ETF 주도주 수급(A+/A 등급)과 꼬리 패턴의 융합 전략

### ① A 등급 + 20일선 긴 아래꼬리 🎯 [눌림목 최적 타점]
* **개념**: `외인/기관 쌍끌이(O) + 20일선 위(O)`인 **A 등급 종목**이 주가 조정을 받다가 **20일 이동평균선 부근에서 긴 아래꼬리를 달고 반등**하는 패턴입니다.
* **전략**: 정배열(A+)이 완성되기 전, 주포(외인/기관)가 20일선을 방어하고 쓸어 담는 구간이므로 **가장 안전하고 가성비 좋은 1차 매수 진입점**이 됩니다.

### ② A+ 등급 + 대량거래 긴 윗꼬리 ⚠️ [단기 리스크 관리]
* **개념**: `쌍끌이 + 20일선 위 + 정배열`을 완벽히 갖춘 **A+ 등급 종목**이라도, 고점권에서 거래량이 터지며 **긴 윗꼬리를 형성**하는 패턴입니다.
* **전략**: 상단 매물 출회 및 세력의 차익 실현 시그널일 수 있으므로 뇌동 매수를 자제하고 **분할 익절 또는 손절선을 바짝 올리는 경계 전략**을 취합니다.

### ③ 전고점 부근 꼬리의 의미 ⛰️
* **전고점 + 긴 윗꼬리**: 이전 고점 저항대 매물을 극복하지 못하고 밀린 신호 (관망)
* **전고점 돌파 + 아래꼬리 지지**: 전고점을 뚫은 후 해당 라인이 강한 지지선으로 바뀐 신호 (추가 가속 매수)
