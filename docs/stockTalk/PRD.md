# stockTalk PRD (초안)

> 상태: 초안 (2026-10-09). 미정 항목은 "열린 질문"에 모아 둔다.
> 배경과 논의는 `brainstorming.md`, 대화는 `talk.md` 참고.

## 1. 한 줄 정의

내 추세추종 매매 규칙이 과거에도 통했는지 숫자로 확인하고, 나중에는 매일 조건에 맞는 종목을 골라주는 개인용 도구.

## 2. 왜 만드나

| 문제 | 해결 |
|---|---|
| 사고 나서야 "왜 빠졌지?"를 고민한다 (예: HMM 2026-10-07 매수) | 과거 수백 번의 매매로 규칙을 미리 검증 |
| 규칙이 말로만 있어 해석이 흔들린다 | 모든 조건을 숫자로 정의하고 프로그램이 판정 |
| 횡보 구간에서 추세추종 신호가 자주 틀린다 | 백테스트로 어떤 필터가 효과 있는지 비교 |

## 3. 사용자

| 항목 | 내용 |
|---|---|
| 주 사용자 | 본인 1명 |
| 외부 공개 | 하지 않음 (공개 시 유사투자자문업 신고 등 법적 검토 필요) |

## 4. MVP 범위

### MVP = 추세추종 백테스터

내가 고른 종목들의 과거 일봉·수급 데이터로, 정해 둔 매수·매도 규칙을 그대로 적용해 결과를 보여준다.

| 구분 | 포함 (MVP) | 제외 (나중에) |
|---|---|---|
| 전략 | 추세추종 | 종가매매(종가베팅) |
| 종목 | 내가 지정한 종목 목록 | 전 종목 자동 스크리닝 |
| 데이터 | 과거 일봉 + 투자자별 매매동향 (장 마감 후 확정치) | 실시간 시세 |
| 매매 | 시뮬레이션만 | 실제 주문 |
| 화면 | 터미널 출력 또는 파일(CSV) | 웹/앱 화면 |

### 기능 목록

| # | 기능 | 설명 |
|---|---|---|
| F1 | 종목·기간 입력 | 종목 코드 목록, 시작일, 종료일 |
| F2 | 데이터 수집 | 일봉(OHLCV), 외국인·기관 순매수 |
| F3 | 매수 판정 | 아래 5-1 조건을 모두 만족한 날 종가 매수 |
| F4 | 매도 판정 | 아래 5-2 조건, 종가 기준 |
| F5 | 매매 목록 | 종목, 매수일·가, 매도일·가, 매도 사유, 수익률 |
| F6 | 성과 요약 | 승률, 평균 이익, 평균 손실, 손익비, 총수익률, 최대 손실폭(MDD) |
| F7 | 비교 기준 | 같은 기간 그냥 보유했을 때 수익률 (생존 편향 점검) |
| F8 | 다음 날 상승 비율 | 매수 다음 날 오른 비율 (참고 지표) |

## 5. 매매 규칙 (brainstorming.md에서 확정한 것)

### 5-1. 매수 (모두 만족 시 당일 종가 매수)

| # | 조건 |
|---|---|
| 1 | 종가 > 20일 이동평균 |
| 2 | 20일 이동평균 > 5거래일 전 20일 이동평균 |
| 3 | 전일까지 3일 연속 외국인 순매수 **AND** 기관 순매수 |

### 5-2. 매도 (종가 기준 판단·실행)

| 구분 | 조건 | 수량 |
|---|---|---|
| 트레일링 스톱 (손절·익절 겸용) | 종가 ≤ 보유 중 최고 종가 -5% (처음엔 매수가 -5%) | 전량 |
| 손절 ② | 종가 < 20일 이동평균 | 전량 |
| 기간 청산 | 매수 후 10거래일 경과 시점에 종가 ≤ 매수가 | 전량 |

익절 ①(+10% 절반 매도)과 익절 ②(5일선 이탈)는 2026-10-09 제거. 트레일링 스톱이 익절 역할을 한다. 피라미딩(40/30/30 분할 매수)은 실험용 옵션으로 백테스트에서 비교한다.

### 5-3. 실험용 추가 필터 (켜고 끌 수 있게)

HMM 사례(이평선 밀집 횡보 구간에서 매수 → 바로 20일선 이탈)에서 나온 아이디어. 효과는 백테스트로 확인한다.

| 필터 | 내용 (수치는 미정) |
|---|---|
| 이평선 밀집 제외 | 5·20·60일선 간격이 일정 % 이내면 매수 안 함 |
| 박스권 돌파 | 최근 N일 고가를 거래량 증가와 함께 돌파 |
| 순매수 최소 금액 | 외국인·기관 순매수가 거래대금의 일정 % 이상 |

## 6. 데이터

| 항목 | 내용 |
|---|---|
| 출처 (후보) | pykrx (KRX 데이터, 무료) |

## 7. 백테스트 가정

| 항목 | 기본값 (미정, 조정 가능) |
|---|---|
| 매수·매도 가격 | 해당일 종가 (실전은 15:20 동시호가라 차이 발생) |
| 비용 | 수수료 + 매도 시 세금, 왕복 약 0.25% (확인 필요) |
| 종목당 투자 금액 | 동일 금액 |
| 같은 종목 보유 중 재신호 | 무시 (추가 매수 안 함) |

## 8. 성공 기준

| 항목 | 목표 |
|---|---|
| MVP 완성 | 종목 5~10개, 3년치로 F1~F8 결과가 나온다 |
| 전략 판단 기준 | 비용 차감 후 승률 40% 이상 **또는** 손익비 2:1 이상, 그리고 그냥 보유 대비 MDD가 작을 것 |
