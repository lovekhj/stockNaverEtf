### 두 가지 전략

| 구분 | A. 추세추종 | B. 종가매매(종가베팅) |
|---|---|---|
| 보유 기간 | 1~2주 | 하루 |
| 수익 구조 | 낮은 승률, 큰 손익비 | 높은 승률, 작은 수익 |
| 상태 | ⏳ 진행 중 | ⬜ |

### 💡 승률보다 기대값

"다음 날 60% 이상 상승"은 목표로 삼지 않는다.
- 개별 종목의 다음 날 방향은 약 50% (동전 던지기에 가까움)
- 60%를 꾸준히 넘는 공개된 방법은 사실상 없음. 백테스트에서 나오면 대부분 과최적화
- 승률이 높아도 손익비가 나쁘면 손실

| 전략 | 승률 / 이익 / 손실 | 10번 결과 |
|---|---|---|
| 승률형 | 60% / +1% / -2% | **-2%** ❌ |
| 추세추종형 | 40% / +10% / -5% | **+10%** ✅ |

### 자금 배분 (초안, 미확정)

| 시기 | 추세추종 | 종가매매 |
|---|---|---|
| 처음 | 100% | 0% |
| 종가매매 검증 후 | 70~80% | 20~30% |

주의:
- 두 전략 모두 매수 포지션 → 시장 급락 시 같이 손실 (위험 분산 아님)
- 둘 다 15:20에 판단·주문 → 시간이 몰림
- 종가매매는 다음 날 09:00~10:00 매도 필요 → 직접 매매 가능 여부 확인 필요

## A. 추세추종 매매법

| 항목 | 내용 |
|---|---|
| 목표 | 1~2주 보유로 수익 |
| 방식 | 추세 + 수급 확인 후 종가 매수 |
| 성과 목표 | 승률 40% 이상, 손익비 2:1 이상 (백테스트로 확인) |

| # | 항목 | 상태 |
|---|---|---|
| A-1 | 종목 선정 기준 | ⏳ 종목 범위 미정 |
| A-2 | 매도 기준 | ✅ |
| A-3 | 데이터 | ⏳ |
| A-4 | 백테스트 기준 | ⬜ |
| A-5 | 검증 방법 | ⬜ |
| A-6 | 예시 (과거 데이터) | ⬜ |

### A-1. 종목 선정 기준

#### 종목 범위 (유니버스) — 제안, 미확정

| 필터 | 기준 |
|---|---|
| 시장 | 코스피 + 코스닥 |
| 거래대금 | 20일 평균 50억 원 이상 |
| 제외 | ETF·ETN, 스팩, 관리종목, 거래정지 |

거래대금 기준 이유: 원하는 가격에 사고팔 수 있고, 세력 조작 위험이 줄어든다.

#### 매수 조건 (확정)

아래를 **모두** 만족하면 **당일 종가에 매수**

| # | 조건 | 목적 |
|---|---|---|
| 1 | 종가 > 20일선 | 한 달 매수자 평균 수익 → 매도 압력 약함 |
| 2 | 20일선 > 5일 전 20일선 | 하락 추세 중 반등 제외 |
| 3 | 어제까지 3일 연속 외국인 **AND** 기관 순매수 | 큰 자금은 나눠 산다 → 추세 지속 |

⚠️ 함정 ①: 당일 수급은 종가 매수 시점에 모른다
- A안 ✅: 어제까지 확정 수급으로 판단 (단순, 백테스트 정확)
- B안 ❌: 장중 잠정 수급 (잠정치 ≠ 확정치)

### A-2. 매도 기준 (확정)

판단·매도 모두 **종가 기준**

| 구분 | 조건 | 수량 |
|---|---|---|
| 트레일링 스톱 (손절·익절 겸용) | 종가 ≤ **보유 중 최고 종가 -5%** (처음엔 매수가 -5%) | 전량 |
| 손절 ② | 종가 < 20일선 | 전량 |
| ~~익절 ①~~ | ~~종가 ≥ 매수가 +10%, 절반~~ → 제거 (피라미딩과 충돌) | - |
| ~~익절 ②~~ | ~~익절 ① 후 종가 < 5일선~~ → 삭제 (트레일링 스톱이 익절 역할) | - |
| 기간 청산 | 10거래일 경과 시점에 종가 ≤ 매수가 (수익 미달) | 전량 |

- 2026-10-09 변경: 손절 ① 기준을 최고 종가로(트레일링 스톱), 익절 ①·② 제거
- 최고 종가가 매수가 +5.3% 이상이면 트레일링 스톱에 걸려도 본전 이상 → 익절이 된다
- 피라미딩(40/30/30)은 이 규칙으로 테스트가 잘 되면 추가
- 손절 ①, ② 중 먼저 오는 조건에서 매도
- 갭하락 시 손실이 -5%를 넘을 수 있음
- -5%, +10%는 백테스트에서 조정 가능

#### 한눈에 보기 (피라미딩 없이, 2026-10-10 정리)

| 구분 | 내용 |
|---|---|
| 전략 | 추세추종 (1~2주 보유). "B. 종가매매(종가베팅)"와는 다른 전략 |
| 사는 때 | 매수 조건이 맞는 날 종가에 한 번, 전액 |
| 기준 금액 | 산 뒤 가장 높았던 종가 (보유 중 최고 종가) |
| 파는 때 | 종가가 기준 금액 -5% 이하면 전량 |

#### 트레일링 스톱 예시 (10,000원 매수)

| 날 | 종가 | 기준 금액 | 매도선 (-5%) | 행동 |
|---|---|---|---|---|
| 1 | 10,000 | 10,000 | 9,500 | 매수 |
| 2 | 10,600 | 10,600 | 10,070 | 보유 |
| 3 | 10,300 | 10,600 | 10,070 | 보유 |
| 4 | 11,200 | 11,200 | 10,640 | 보유 |
| 5 | 10,600 | 11,200 | 10,640 | 전량 매도 (+6%) |

- 기준 금액은 오를 때만 올라가고 내려가지 않는다 (3일차)
- 장중 고가는 보지 않고 종가만 본다
- 사자마자 빠지면 기준 금액이 매수가라서 -5% 손절이 된다
- 이 예시는 트레일링 스톱만 보여준다. 20일선 이탈, 기간 청산은 위 표대로 따로 적용

손익비: 1번 성공(+10%) = 2번 실패(-10%) → **승률 약 34% 이상이면 본전 이상** (비용 별도)

검토했던 선택지:

| 구분 | 선택 | 제외 |
|---|---|---|
| 손절 | -5% 또는 20일선 중 먼저 | 고정 -5%만, 20일선만 |
| 익절 | +10% 절반 + 5일선 이탈 | +10% 전량, 5일선만 |
| 기간 청산 | 10거래일 | 5거래일, 없음 |

### A-3. 데이터

#### 필요한 데이터

| 데이터 | 용도 | 시점 |
|---|---|---|
| 일봉 (OHLCV) | 이동평균, 손익 | 장 마감 후 |

⚠️ 함정 ②: "오늘 종가"도 15:20에는 확정 전

| 시간 | 상황 |
|---|---|
| ~15:20 | 정규장, 현재가 변동 |
| 15:20~15:30 | 종가 동시호가 |
| 15:30 | 종가 확정 |

→ 실전: 15:20 직전 현재가를 종가로 간주해 판단 → 동시호가 주문. 동시호가에서 가격이 크게 움직이면 백테스트와 차이가 생긴다.

#### 데이터 출처

| 출처 | 용도 | 지연 |
|---|---|---|
| **pykrx** (Python) | 과거 데이터, 백테스트 | 장 마감 후 |
| **한국투자증권 Open API** | 실전 판단, 주문 | 실시간 |
| 키움증권 API | 실전 (대안) | 실시간 |
| 네이버 금융 크롤링 | 비추천 | △ |

출처별 주의:
- pykrx: 무료, 수급 데이터 있음. KRX 사이트를 긁는 비공식 방식이라 사이트가 바뀌면 멈출 수 있음 → 구현 전 동작 확인 필수
- 한국투자증권: 무료(계좌 필요), REST 방식이라 Mac에서 무난
- 키움: 기존 OpenAPI+는 Windows 전용, REST API 지원 여부 확인 필요
- 크롤링: 약관 문제, 구조 변경 위험

**추천 조합**: pykrx(백테스트) + 한국투자증권 Open API(실전)

## B. 종가매매법 (종가베팅)

A 완료 후 같은 순서로 진행: 종목 선정 → 매도 → 데이터 → 백테스트 → 검증 → 예시

현재까지 메모:
- 당일 강하게 마감한 종목(고가 근처 마감, 거래대금 급증, 신고가 등)을 종가 매수 → 다음 날 오전 매도
- 현실적 승률 50~55%. 60% 보장 아님
- 매일 왕복 매매 → 수수료·세금 부담 큼, 비용 차감 후 수익 확인 필요
